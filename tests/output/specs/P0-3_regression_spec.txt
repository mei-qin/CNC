2. 回归风险点
   R1  WHILE 关键字误匹配
       M3 在 parse_gcode_line 入口加 W-H-I-L-E+!isalpha 检测
       若 NC 行首字母是 W 可能误入
   R2  END 关键字误匹配
       END 分支检测 E-N-D+!isalpha
       M1/M2 用例无 END 开头, 但需核对
   R3  scan_while_pairs 错误拒绝
       M1/M2 用例无 WHILE 行, 预扫描应输出 "配对完成: 0 对"
       若 strstr_skip_ws 误判, Program_Load 返回 NULL, 文件无法运行
   R4  GCodeProgram_t 结构布局回归
       M3 加了 do_to_end[MAX_PROGRAM_LINES] + end_to_do[MAX_PROGRAM_LINES]
       共 160KB BSS, 若 Program_Init 未正确初始化可能干扰 n_labels 二分
   R5  词法分支顺序错误
       M3 的 WHILE/END 分支必须在 IF 分支之前 (关键字长度递减)
