【未提交 — 本周新增】G93 时间绝对守恒体系 + 多项算法重构
----------------------------------------------------------------
涉及文件: axis_cfg.h, axis_ctrl.h, axis_ctrl.c, planner.c,
          gcode_parser.c, bspline_engine.c, ecat_core.c

这是对 G93/G94 数据流的彻底重构,共 4 轮迭代修复:

【Round 1】G93 时间塌陷根治 + M 代码显式屏障
  1. 新增 api_push_trajectory_g93(...): G93 模式豁免 max_speed/max_acc/
     max_dec/max_jerk 短板限幅,保证 phys_speed = phys_dist/dt_per_seg
     不被静默压低。
  2. gcode_parser.c RTCP 直线/圆弧 G93 路径改走强一致性入队。
  3. planner_recalculate 反向扫描开头插入显式 MCODE 屏障:
     若 (curr+1) 段为 CMD_TYPE_MCODE,强制 s_curr.v_end=0,
     防御性加固 (现有 calculate_junction_speed 已能间接保证)。

【Round 2】G93 强一致性纯匀速预计算 + 免抹圆透传
  1. TrajectorySegment_t 新增 is_g93_strict 字段。
  2. api_push_trajectory_impl 重构签名,新增 is_g93_strict/g93_dt_sec/
     is_fillet 三个参数;mutex 内对 G93 段预计算纯匀速绝对解析参数
     (T4=T_total, v0..v6=v_target, s4..s6=total_distance, 全部 jerk=0)。
  3. 新增 api_push_trajectory_passthrough 包装: is_fillet=1,供 B-Spline
     透传段调用,planner_fillet_preprocess 自动跳过。
  4. planner.c 三处尊重 is_g93_strict:
     - recompute_scurve_profile 入口跳过 S 曲线重算,保护预计算值;
     - 反向扫描 is_g93_strict 段 v_start 锁定 v_target;
     - 正向扫描 is_g93_strict 段 v_end 锁定 v_target。
  5. G93 路径在 gcode_parser.c / bspline_engine.c 三处入队点传 dt_per_seg。

【Round 3】TraceLogger 停止瞬间漏记 (Falling Edge Latch)
  1. ecat_core.c RT 线程探针段加 static last_is_moving 状态变量。
  2. 触发条件: current_is_moving || (下降沿 !current && last)。
  3. 下降沿那一帧强制 log_v_target=0.0,消除"速度未归零"假象。
  4. 真实硬件探针: 运动中 cycle%5 降采样 + 下降沿立即记录。
  5. 仿真采集: 1ms 全量 + 下降沿。单次下降沿,单次记录。

【Round 4】时空切分谬误根治 + B-Spline 等距重离散化
  1. G93 时间切分 (gcode_parser.c): 抛弃 0.5mm 空间切分,
     num_segments = ceil(T_sec*1000),与 RT 线程 1ms 周期对齐,
     封顶 20000 防队列爆掉。G94 仍走 0.5mm 空间切分。
  2. B-Spline 前向追踪重离散化 (bspline_engine.c): 抛弃 LUT 二分反查
     (256 采样精度不足,步长 CV=0.58),改用 t_step=0.0005 前向累加弧长,
     达到 step_size_mm 立即入队,等距性显著提升。
  3. 暴力锐角截断 (bspline_engine.c is_sharp_corner): 抛弃 acos
     (在 cos_angle → ±1 处数值不稳定),预计算 cos_thresh=cos(threshold),
     直接比较 cos_angle < cos_thresh (数学等价,cos 在 [0,π] 单调递减)。

  src/kinematics.c     — 4x4 矩阵库 + 三构型动态逆解
  src/planner.c        — G64 前瞻 + 7段S曲线预计算

  src/smc_api.c        — 用户层 API 封装

线程模型:
  ecat_thread_rt      — 1ms 实时线程, SCHED_FIFO 优先级99
    (CSP 位置命令下发, 7段S曲线绝对解析插补, 跟随误差监控 0x60F4,
     龙门同步检测, CiA402 状态机, 优雅下电状态机 dorun==2,
     探针下降沿锁存 last_is_moving)
  ecat_thread_chk     — 10ms 非实时线程
    (从站状态检测, RT 日志异步输出, 队列饥饿看门狗,
     解析器卡死二级检测 2s 超时)
  parser_thread_func  — 非实时解析线程
    (G 代码文件逐行解析, 模态状态管理, G93/G94 进给模式,
     G93 1ms 时间切分 (封顶 20000), 动态轴映射查表,
     RTCP 逆解微段打碎, 推入命令队列)
  bspline_thread_func — B-Spline 平滑后台线程 (绑定 CPU 核心)
    (脏点队列消费, 锐角切批 (cos_thresh 比较),
     前向追踪重离散化 (t_step=0.0005), 推入命令队列)
  trace_logger/落盘线程 — 仿真轨迹双缓冲落盘

数据流:
  G代码文件
    -> parse_gcode_line (模态+轴映射+G93/G94+注释过滤+G53非模态)
    -> RTCP 微段打碎 generate_linear_rtcp/arc_trajectory
       (G93: 1ms 时间切分 ceil(T_sec*1000), 封顶 20000)
    -> CutterComp_PushPoint (G41/G42 2D 偏置, 直线段路由)
    -> BSpline_PushDirtyPoint (G01+BSpline 模式)
       -> bspline_thread_func: 锐角切批 + 前向追踪重离散化
    -> api_push_trajectory / _g93 / _passthrough / _mcode
       (4 个 push 变体, mutex 保护, release 写屏障)
    -> CommandQueue_t -> planner_recalculate (mutex + plan_tail结界)
       -> planner_fillet_preprocess (G64 圆角, is_fillet 跳过)
       -> 反向扫描 (MCODE 显式屏障 + G93 strict 锁定)
       -> 正向扫描 (G93 strict 锁定)
       -> 动态安全释放窗口 (精确制动距离 + M代码屏障 + 段数上限200)
       -> recompute_scurve_profile (is_g93_strict 跳过, 保留纯匀速)
    -> atomic_store_release(is_ready=1)
    -> ecat_thread_rt atomic_load_acquire -> 弹出段
    -> Interpolator_t 7段绝对解析插补 (T1-T7 多项式求值)
       (G93 strict 段: T4=T_total, v0..v6=v_target, 纯匀速)
    -> 微段快进 (T_total<0.5ms 直接snap)
    -> 探针 Falling Edge Latch (last_is_moving 检测停止瞬间)
    -> 各轴 current_cmd_pos -> PDO 写入 -> 驱动器

插补架构 (7段式 S 曲线 + G93 强一致性纯匀速):
  Planner (非RT): 预计算 T1-T7/v0-v6/s0-s6/j1-j7/a2/a6
    G93 strict: 预计算纯匀速 (T4=T_total, jerk 全 0)
  RT 线程: virtual_time_ms 与 T1-T7 比较, 无状态绝对解析
    s(τ) = s_n + v_n·τ + ½·a_n·τ² + ⅙·j_n·τ³
  Feedhold: time_scale 控制虚拟时间流速, 平滑刹车/恢复

G93 时间绝对守恒体系:
  1. 切分: 时间切分 num_segments=ceil(T_sec*1000), 封顶 20000
  2. 入队: api_push_trajectory_g93 豁免短板限幅
  3. 预计算: mutex 内设 T4=T_total, v0..v6=v_target
  4. 保护: recompute_scurve_profile 跳过 is_g93_strict
  5. 锁定: 反向/正向扫描 v_start/v_end = v_target
  6. RT 解析: 1ms 周期匀速推演,绝对遵守 T_sec

下电时序:
  SMC_Close (非RT): dorun=2 → 阻塞等待 dorun==0 → EtherCAT 降级
  RT 线程 dorun==2: Step0 抱闸闭合(500ms) → Step1 CiA402降级(≤1000ms)
    → dorun=0 交还控制权

关键同步机制:
  - planner_mutex: 保护 planner_recalculate 对队列的读写原子性
  - _Atomic is_ready: producer (planner) release 写入,
    consumer (RT线程) acquire 读取, C11 内存模型保证数据可见性
  - _Atomic is_moving: RT 线程写, 非RT 线程读, ARM 弱序安全
  - _Atomic alarm_reset_request: 非RT 请求, RT 安全点消费
  - plan_tail 结界: 已释放段对 planner 只读, 禁止覆写
  - bspline_mutex + bspline_cond: 脏点队列生产消费同步
  - static last_is_moving (RT 线程局部): 探针下降沿锁存

TxPDO 映射 (每从站 10 字节):
  偏移 0-1: 0x6041 状态字 (uint16)
  偏移 2-5: 0x6064 实际位置 (int32)
  偏移 6-9: 0x60F4 跟随误差 (int32)
